## 📌 Sobre o projeto

O **Diogenes Northeastern Technology** é um projeto de site pessoal desenvolvido para compartilhar meus interesses, publicações e experiências, unindo o universo da tecnologia à valorização da cultura nordestina.

Este projeto também representa o início da minha jornada prática no desenvolvimento web, permitindo aprender, experimentar e aprimorar minhas habilidades em programação.

## 🎯 Objetivos

- 💻 Aprender e praticar desenvolvimento web.
- 🌵 Valorizar a cultura e as tradições nordestinas.
- 🎵 Compartilhar músicas e artistas favoritos.
- 🎮 Apresentar jogos e conteúdos do universo gamer.
- 📸 Compartilhar fotos, momentos e experiências.
- 🚀 Desenvolver um espaço pessoal que possa evoluir com novos recursos.

## ✨ Funcionalidades

- 🏠 Página inicial com publicações recentes.
- 🎵 Seção dedicada à música.
- 🎮 Seção dedicada aos jogos.
- 📸 Galeria de fotos e publicações.
- 👤 Página com informações sobre o desenvolvedor.
- 🔐 Painel administrativo para gerenciar publicações.
- 🖼️ Sistema de banners com imagens, navegação por setas e troca automática.
- 💬 Área de comentários nas publicações.
- 📱 Layout adaptável a diferentes tamanhos de tela.

> Algumas funcionalidades podem depender da configuração atual do projeto e do serviço de armazenamento utilizado.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilização, cores e responsividade.
- **JavaScript** — interatividade e funcionalidades.
- **LocalStorage** — armazenamento local de dados no navegador.

## ▶️ Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confira se os arquivos e as imagens estão nos caminhos corretos.
4. Abra o arquivo `index.html` no navegador. Você também pode utilizar a extensão Live Server do VS Code para facilitar o desenvolvimento.
